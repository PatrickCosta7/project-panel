## Front-end Project Panel
Front-end do painel feito para cadastrar filmes e séries, utilizando React.js e scss.

## Atenção
 - Esse projeto somente irá funcionar com sua API rodando de fundo, o link abaixo contém seus códigos assim como instruções de como subir.
 - `https://github.com/PatrickCosta7/project_panel_API.git`

## Pré-requisitos:
    - Node 18+: `https://nodejs.org/en/download/package-manager`

## Subindo o front:
    - Inicie a API
    - Usando o terminal, digite os comandos abaixo
    - `$ npm install` -> Instala todas as dependências do projeto
    - `$ npm start` -> Inicia o projeto
    - Acesse link `http://localhost:3000`.
