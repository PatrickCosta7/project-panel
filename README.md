## Front-end Project Panel
Front-end do painel feito para cadastrar filmes e séries, utilizando React.js e scss.

## Atenção
Esse projeto somente irá funcionar com sua API rodando de fundo, o link abaixo contém seus códigos assim como instruções de como subir:
[Project Panel](https://github.com/PatrickCosta7/project_panel_API.git)

## Subindo o front:

Será necessário ter Node.js (versão 18 ou superior) instalado em sua máquina: [Baixar Node.js](https://nodejs.org/en/download/package-manager)

- Certifique que a API esteja rodando em localhost:8001

Baixe o projeto, acesse sua pasta pelo terminal e instale as depedências com o comando:

    npm install
 
Após isso, para iniciar o projeto digite:

    npm start

Abra [http://localhost:3000](http://localhost:3000) em seu navegador para visualizar o projeto.
